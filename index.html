Cấu hình OCR báo giá
AI OCR Provider
Chọn engine xử lý báo giá. Gemini đọc trực tiếp ảnh/PDF và bóc JSON. OCR.Space dùng API OCR miễn phí để lấy text, sau đó hệ thống tự tách bảng báo giá thành dòng phụ tùng để bạn kiểm tra/chỉnh lại trước khi tra kho. API key được lưu riêng theo từng tài khoản trong Firestore collection user_api_keys, không dùng chung giữa các user.
Đang đọc cấu hình từ Firestore theo tài khoản hiện tại.
